Mined ledgers

37 real mainnet and testnet ledgers from the public data lake, for shapes a standalone generator cannot produce, or that are worth having as real network bytes: eviction at the cap, settings votes, a mainnet freeze, protocol-12 V0 envelopes.

In plain words

What it is. Real mainnet and testnet ledgers, downloaded from the public data lake with their hashes and the query that found them.

Why it matters. Some shapes only happen on a live network, such as eviction at the per-ledger cap or a validator vote. These are the real bytes, not a reconstruction.

Some shapes only happen on a real network, and some are worth having as real network bytes. Examples:

  • eviction at the per-ledger cap;
  • validator settings votes;
  • a mainnet freeze of ledger keys (CAP-0077);
  • protocol-12 V0 envelopes;
  • protocol-22 refunds;
  • multi-stage parallel Soroban phases.

mined/ holds those as real LedgerCloseMeta, fetched from SDF's public data lake and located with BigQuery over the public Hubble dataset. The queries are in mined/queries/.

FileWhat it is
mined/ledgers/<network>-<seq>.lcm.xdr.zstOne ledger, zstd-compressed. Its sha256 and size describe the decompressed bytes: the lake object minus its 12-byte batch header
mined/index.jsonOne record per shape found in a ledger: the lake URL, the stellar-core version that wrote it, how it was located, the findings with exact JSON paths, and why readers break on it

make verify also runs tools/mined-verify.mjs. Every file must match its hash, round-trip byte for byte through native rs-stellar-xdr, and carry the recorded sequence and protocol. Every finding's transaction and JSON path must be present. make coverage reports the union arms these ledgers reach: 289 of 499.

Network data, not entries

These ledgers were written by SDF's Galexie with its default flags, so their metadata differs from a default node's (see Found while building). Most are not corpus entries: entries carry facts and hazards, and these carry findings. The catalog also compiles entries from them: 37 entries so far, built from 22 of these ledgers, the signed-payload signer among them.
