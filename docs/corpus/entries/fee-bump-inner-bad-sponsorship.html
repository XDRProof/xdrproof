A fee bump whose inner transaction leaves a sponsorship open: inner txBAD_SPONSORSHIP

The inner transaction begins sponsoring an account and never ends it.

The shape

The inner transaction begins sponsoring an account and never ends it. The fee bump's result is txFEE_BUMP_INNER_FAILED; the inner result is txBAD_SPONSORSHIP, a transaction-level code inside InnerTransactionResult. The fee source pays; nothing the inner transaction did is kept.
