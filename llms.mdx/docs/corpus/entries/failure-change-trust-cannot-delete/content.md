# CHANGE_TRUST fails with CHANGE_TRUST_CANNOT_DELETE (/docs/corpus/entries/failure-change-trust-cannot-delete)

Where it sits, inside `LedgerCloseMeta` (CAP-0038):

- H-C1: OperationResult.change_trust.cannot_delete in a closed ledger
- H-C8: deleting a trustline a pool-share trustline still uses

## The shape

A transaction whose CHANGE_TRUST operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (cannot_delete). Deleting an NRV trustline (limit 0) while an XLM/NRV pool-share trustline still depends on it.
