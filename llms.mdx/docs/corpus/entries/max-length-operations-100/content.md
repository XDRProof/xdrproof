# A transaction with the maximum 100 operations, each to a different muxed ID (/docs/corpus/entries/max-length-operations-100)

Where it sits, inside `LedgerCloseMeta` (pre-cap, CAP-0027):

- H-B12: Transaction.operations at its maximum of 100
- H-A1: 100 muxed destination IDs of one account in one transaction

## The shape

operations<100> full: 100 payments to M(bob, 1) … M(bob, 100). The classic transaction set holds exactly 100 operations, so this transaction fills its ledger alone.
