# A transaction whose only signature is a hash-x preimage (/docs/corpus/entries/signer-hashx-signed)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-A4: DecoratedSignature carrying a hash-x preimage

## The shape

The signature is the preimage itself, not an ed25519 signature: readers that verify every signature as ed25519 reject it.
