# The same classic payment under three node-flag profiles (/docs/corpus/entries/profiles-classic-payment-meta-by-flags)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-F9: same ledger, three emitter-flag profiles
- H-F7: LedgerCloseMetaExt v1 under base and galexie flags, v0 under bare

## The shape

The same ledger as written by a node with base flags, with Galexie's six flags, and with none. The ledger is identical; the metadata is not: with no flags the classic transfer event and the fee events are absent and LedgerCloseMeta has no ext v1.
