# ACCOUNT_MERGE fails with ACCOUNT_MERGE_NO_ACCOUNT (/docs/corpus/entries/failure-account-merge-no-account)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C1: OperationResult.account_merge.no_account in a closed ledger

## The shape

A transaction whose ACCOUNT_MERGE operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and none of its operations change state. The result carries the operation's result code (no_account). Readers that skip failed transactions lose the fee and sequence change; readers that assume a failed transaction changed something record effects that never happened.
