# With diagnostic events on, every contract event appears twice (/docs/corpus/entries/profiles-galexie-diagnostic-double-emission)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-E3: contract event repeated in diagnostic_events
- H-F9: diagnostic events only under the galexie profile

## The shape

Galexie's default flags include ENABLE_SOROBAN_DIAGNOSTIC_EVENTS. The put's contract event appears in the operation's events and again, type contract, among the diagnostic events; a core_metrics event invoke_time_nsecs carries wall-clock time, so the bytes differ between nodes. stellar-etl#452.
