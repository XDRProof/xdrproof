# A config-settings upgrade: Soroban transaction limit and three frozen trustlines (/docs/corpus/entries/upgrade-config-lanes-and-freeze)

Where it sits, inside `LedgerCloseMeta` (CAP-0046, CAP-0077):

- H-F10: LEDGER_UPGRADE_CONFIG updating contract_execution_lanes and frozen_ledger_keys
- H-D12: frozen-key list grown by a config upgrade

## The shape

LEDGER_UPGRADE_CONFIG with two settings in one set: contract_execution_lanes (ledgerMaxTxCount 2) and frozen_ledger_keys (three trustlines). The new values appear only in upgradesProcessing, after the ledger's transactions.
