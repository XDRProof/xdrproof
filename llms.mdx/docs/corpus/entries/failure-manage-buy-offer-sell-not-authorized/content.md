## The shape

A transaction whose MANAGE_BUY_OFFER operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (sell_not_authorized). The seller holds 10 ARQ on a deauthorized trustline. Core checks a zero balance before authorization (ManageOfferOpFrameBase.cpp), so an unauthorized trustline that never held ARQ reports underfunded instead.
