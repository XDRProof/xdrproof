# A pool deposit: transfer events to an L… address (/docs/corpus/entries/pool-deposit-l-address-event)

Where it sits, inside `LedgerCloseMeta` (CAP-0038, CAP-0067):

- H-C8: pool entry created by ChangeTrust to pool shares; LiquidityPoolDeposit only updates it
- H-A5: liquidity-pool address L… in a CAP-0067 event topic

## The shape

CHANGE_TRUST to pool shares creates the liquidity-pool entry (not the deposit, which only updates it), and LIQUIDITY_POOL_DEPOSIT emits transfer events whose destination is the pool, rendered as an L… strkey (CAP-0067). Readers that create pools on deposit, or expect G or C addresses in event topics, get both wrong.
