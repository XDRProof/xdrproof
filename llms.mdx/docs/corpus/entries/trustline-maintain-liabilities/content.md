# A trustline set to authorized-to-maintain-liabilities (/docs/corpus/entries/trustline-maintain-liabilities)

Where it sits, inside `LedgerCloseMeta` (CAP-0018, CAP-0035):

- H-C10: trustline flag AUTHORIZED_TO_MAINTAIN_LIABILITIES

## The shape

SET_TRUST_LINE_FLAGS clears AUTHORIZED (1) and sets AUTHORIZED_TO_MAINTAIN_LIABILITIES (2) on bob's XPF trustline, which also carries TRUSTLINE_CLAWBACK_ENABLED (4) inherited from the issuer: flags go from 5 to 6. Readers that test flags == 2 instead of the bit miss the state; readers that ignore the clawback bit miss that the balance can be clawed back.
