# CLAWBACK fails with CLAWBACK_NOT_CLAWBACK_ENABLED (/docs/corpus/entries/failure-clawback-not-clawback-enabled)

Where it sits, inside `LedgerCloseMeta` (CAP-0035):

- H-C1: OperationResult.clawback.not_clawback_enabled in a closed ledger
- H-C10: clawback from a trustline without the clawback flag

## The shape

A transaction whose CLAWBACK operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (not_clawback_enabled). The issuer never enabled clawback, so its trustlines carry no clawback flag.
