# ACCOUNT_MERGE fails with ACCOUNT_MERGE_IMMUTABLE_SET (/docs/corpus/entries/failure-account-merge-immutable-set)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C1: OperationResult.account_merge.immutable_set in a closed ledger
- H-C11: merging an AUTH_IMMUTABLE issuer

## The shape

A transaction whose ACCOUNT_MERGE operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (immutable_set). An issuer with AUTH_IMMUTABLE can never be merged.
