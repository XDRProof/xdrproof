# An XLM SAC transfer creates a G account (/docs/corpus/entries/sac-xlm-transfer-creates-account)

Where it sits, inside `LedgerCloseMeta` (CAP-0073):

- H-D2: XLM SAC transfer creates an account entry

## The shape

Since CAP-0073 the native SAC can transfer to an account that does not exist: the transfer creates it with 25 XLM. There is no CREATE_ACCOUNT operation. Readers that only create accounts from CREATE_ACCOUNT miss dave.
