# A contract deploy whose authorization root carries a 245-deep chain (/docs/corpus/entries/auth-deploy-with-tree-depth-245)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-B7: 245-deep auth tree with a contract deploy
- H-B13: a valid ledger the WASM decoder rejects

## The shape

The deploy succeeds and creates an instance; its auth root is the CreateContractV2 function with 244 nested never-called invocations. wallet-backend's contract-deploy walk (#820) runs only when an instance is created, so this is the ledger that exercises it.
