## The shape

A transaction whose RESTORE_FOOTPRINT operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (resource_limit_exceeded). Restoring an evicted persistent entry while declaring 0 write bytes: the restored entry has to be written.
