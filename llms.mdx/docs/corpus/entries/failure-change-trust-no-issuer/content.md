# CHANGE_TRUST fails with CHANGE_TRUST_NO_ISSUER (/docs/corpus/entries/failure-change-trust-no-issuer)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C1: OperationResult.change_trust.no_issuer in a closed ledger

## The shape

A transaction whose CHANGE_TRUST operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and none of its operations change state. The result carries the operation's result code (no_issuer). Readers that skip failed transactions lose the fee and sequence change; readers that assume a failed transaction changed something record effects that never happened.
