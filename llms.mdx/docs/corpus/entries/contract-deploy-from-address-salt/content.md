# A contract deployed from an address and salt (/docs/corpus/entries/contract-deploy-from-address-salt)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-D5: CreateContractV2 from address + salt
- H-G1: contract ID derived from the network ID: different in the mainnet and testnet variants of the same recipe

## The shape

CREATE_CONTRACT_V2 from alice with salt sha256("xdrproof:kit:0"): the contract ID is derived from the network ID, the deployer and the salt.
