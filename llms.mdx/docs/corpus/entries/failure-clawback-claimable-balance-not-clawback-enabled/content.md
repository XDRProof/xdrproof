## The shape

A transaction whose CLAWBACK_CLAIMABLE_BALANCE operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (not_clawback_enabled). The issuer never enabled clawback, so its claimable balance carries no clawback flag.
