# Revoking a sponsorship moves the reserve back (/docs/corpus/entries/sponsorship-revoke)

Where it sits, inside `LedgerCloseMeta` (CAP-0033):

- H-C3: RevokeSponsorship of a data entry
- H-D3: sponsorship moves between accounts with no create or delete

## The shape

REVOKE_SPONSORSHIP on eve's data entry: the entry stays, its sponsoring ID is cleared, and the reserve moves from sponsor to eve.
