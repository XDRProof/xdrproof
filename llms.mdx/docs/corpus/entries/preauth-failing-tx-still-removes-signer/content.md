# A pre-authorized transaction that fails still removes its signer (/docs/corpus/entries/preauth-failing-tx-still-removes-signer)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C15: failed transaction removes its pre-auth signer
- H-A4: pre-auth signer removed by a failing transaction

## The shape

The payment fails (no trustline), yet core removes the T… signer in tx_changes_before: a failed transaction changed state.
