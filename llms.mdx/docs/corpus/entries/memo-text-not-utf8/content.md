# A 28-byte text memo that is not valid UTF-8, mapped into the transfer event (/docs/corpus/entries/memo-text-not-utf8)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-B5: MEMO_TEXT bytes that are not UTF-8
- H-A6: MEMO_TEXT carried into the transfer event as to_muxed_id (string)

## The shape

MEMO_TEXT holds 28 raw bytes that are not UTF-8 (the maximum length). CAP-0067 copies it into the payment's transfer event as to_muxed_id (a string). Readers that decode either as UTF-8 lose or mangle it.
