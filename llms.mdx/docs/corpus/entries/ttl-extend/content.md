# EXTEND_FOOTPRINT_TTL changes only a TTL entry (/docs/corpus/entries/ttl-extend)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-D4: ExtendFootprintTTL updates only the ttl entry
- H-D8: TTL entry named by key_hash

## The shape

The data entry is untouched; only its TTL entry, named by sha256 of the data's LedgerKey, changes.
