# CLAIM_CLAIMABLE_BALANCE fails with CLAIM_CLAIMABLE_BALANCE_CANNOT_CLAIM (/docs/corpus/entries/failure-claim-claimable-balance-cannot-claim)

Where it sits, inside `LedgerCloseMeta` (CAP-0023):

- H-C1: OperationResult.claim_claimable_balance.cannot_claim in a closed ledger

## The shape

A transaction whose CLAIM_CLAIMABLE_BALANCE operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and none of its operations change state. The result carries the operation's result code (cannot_claim). Readers that skip failed transactions lose the fee and sequence change; readers that assume a failed transaction changed something record effects that never happened.
