## The shape

A transaction whose EXTEND_FOOTPRINT_TTL operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (insufficient_refundable_fee). The resource fee is exactly the non-refundable part, the smallest fee core accepts at submission: nothing is left for the rent the extension owes.
