# Four trustlines from three operation sources in one transaction, one alphanum-12 at the int64-max limit (/docs/corpus/entries/trustline-multi-source-alphanum12-max-limit)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

## The shape

One transaction, three operation sources (alice, bob, mm), alphanum-4 and alphanum-12 assets, and a trustline limit of 922337203685.4775807 (int64 max stroops). Readers that attribute every operation to the transaction source, or parse the limit as a float, get it wrong.
