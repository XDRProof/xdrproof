# ACCOUNT_MERGE fails with ACCOUNT_MERGE_DEST_FULL (/docs/corpus/entries/failure-account-merge-dest-full)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C11: merge into an account with no room below i64::MAX
- H-C17: native buying liabilities near i64::MAX
- H-B3: an account balance plus buying liabilities near i64::MAX

## The shape

A transaction whose ACCOUNT_MERGE operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (dest_full). The destination sells 429.4967297 NRV at 2147483647 XLM each: native buying liabilities of 2^63 - 2147483649 stroops, which leave it about 164 XLM of room below i64::MAX (TransactionUtils.cpp, addBalance). The 300 XLM merged in does not fit.
