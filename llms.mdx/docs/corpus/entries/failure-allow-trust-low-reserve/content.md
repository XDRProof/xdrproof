# ALLOW_TRUST fails with ALLOW_TRUST_LOW_RESERVE (/docs/corpus/entries/failure-allow-trust-low-reserve)

Where it sits, inside `LedgerCloseMeta` (pre-cap, CAP-0038, CAP-0033):

- H-C1: OperationResult.allow_trust.low_reserve in a closed ledger
- H-D9: AllowTrust revocation whose pool-share redemption cannot fund its claimable balances
- H-C3: AllowTrust revocation inside a sponsorship sandwich whose sponsor is at its minimum balance

## The shape

A transaction whose ALLOW_TRUST operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (low_reserve). The same as SET_TRUST_LINE_FLAGS_LOW_RESERVE, through the older AllowTrust operation: the redeemed pool shares need claimable-balance reserves the sandwich's sponsor does not have.
