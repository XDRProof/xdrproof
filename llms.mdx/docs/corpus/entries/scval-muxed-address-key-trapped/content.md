# A muxed ScAddress as a contract-data key traps (/docs/corpus/entries/scval-muxed-address-key-trapped)

Where it sits, inside `LedgerCloseMeta` (CAP-0067, CAP-0046):

- H-A11: muxed ScAddress inside a contract-data key: trapped
- H-C6: Soroban failure: trapped

## The shape

CAP-0067: a muxed ScAddress may not appear in a contract-data key. The address is valid in the arguments and even in the footprint's LedgerKey, but the put traps.
