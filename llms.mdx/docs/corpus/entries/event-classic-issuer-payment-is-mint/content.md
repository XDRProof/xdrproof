# A payment from the issuer is a mint event, not a transfer (/docs/corpus/entries/event-classic-issuer-payment-is-mint)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-E1: PaymentOp from the issuer emits a CAP-0067 mint event

## The shape

Under CAP-0067 a payment whose source is the asset issuer emits mint (not transfer). Readers that only follow transfer events miss issuance.
