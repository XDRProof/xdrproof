# SET_TRUST_LINE_FLAGS fails with SET_TRUST_LINE_FLAGS_NO_TRUST_LINE (/docs/corpus/entries/failure-set-trust-line-flags-no-trust-line)

Where it sits, inside `LedgerCloseMeta` (CAP-0035):

- H-C1: OperationResult.set_trust_line_flags.no_trust_line in a closed ledger

## The shape

A transaction whose SET_TRUST_LINE_FLAGS operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and none of its operations change state. The result carries the operation's result code (no_trust_line). Readers that skip failed transactions lose the fee and sequence change; readers that assume a failed transaction changed something record effects that never happened.
