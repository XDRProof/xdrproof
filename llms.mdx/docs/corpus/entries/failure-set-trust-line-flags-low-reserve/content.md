## The shape

A transaction whose SET_TRUST_LINE_FLAGS operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (low_reserve). Revoking ARQ from an account that holds XLM/ARQ pool shares redeems them into new claimable balances (CAP-0038). The account is inside a sponsorship sandwich, so the sandwich's sponsor must fund the balances' reserves, and it sits at its minimum balance (TransactionUtils.cpp, removeOffersAndPoolShareTrustLines). Operations 0 and 2 report success in the failed transaction.
