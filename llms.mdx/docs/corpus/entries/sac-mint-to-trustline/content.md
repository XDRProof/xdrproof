# SAC mint into a trustline the SAC created (/docs/corpus/entries/sac-mint-to-trustline)

Where it sits, inside `LedgerCloseMeta` (CAP-0046, CAP-0067):

- H-E1: SAC mint event into a classic trustline

## The shape

The issuer mints XPF to bob through the SAC: the classic trustline balance changes and a mint event is emitted.
