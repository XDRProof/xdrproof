## The shape

A transaction whose CHANGE_TRUST operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and nothing it did is kept. The result carries the operation's code (trust_line_missing). A pool-share trustline for XLM/NRV from an account with no NRV trustline.
