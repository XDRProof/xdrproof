# CREATE_ACCOUNT fails with CREATE_ACCOUNT_UNDERFUNDED (/docs/corpus/entries/failure-create-account-underfunded)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C1: OperationResult.create_account.underfunded in a closed ledger

## The shape

A transaction whose CREATE_ACCOUNT operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and none of its operations change state. The result carries the operation's result code (underfunded). Readers that skip failed transactions lose the fee and sequence change; readers that assume a failed transaction changed something record effects that never happened.
