# A transaction valid at submission fails at apply with txBAD_AUTH_EXTRA (/docs/corpus/entries/tx-apply-time-bad-auth-extra)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-C16: TransactionResult.txBAD_AUTH_EXTRA at apply: a signature needed at submission is unused once the master weight rises

## The shape

u6 needs weight 2: its master key and s6 both sign, and both signatures are used at submission. A classic transaction earlier in the same ledger raises the master key's weight to 2. At apply core's signature checker stops once the master key meets the threshold (SignatureChecker.cpp), so s6's signature goes unused and the transaction fails with txBAD_AUTH_EXTRA. Readers that treat BAD_AUTH_EXTRA as a submission-only code meet it in a closed ledger.
