# One payment with a muxed transaction source, operation source and destination (/docs/corpus/entries/muxed-payment-every-position)

Where it sits, inside `LedgerCloseMeta` (CAP-0027):

- H-A1: Transaction.sourceAccount, Operation.sourceAccount and PaymentOp.destination as MuxedAccount
- H-A2: muxed IDs 1, 2^63 (above int64 max) and 2^64-1

## The shape

A payment where the transaction source, the operation source and the destination are all muxed accounts (M…), with IDs 1, 2^64-1 and 2^63. Each M address is a base account plus a 64-bit ID: the ID must be kept, and balances belong to the base account. Readers that store the M string as the account, or drop the ID, misattribute or lose the payment.
