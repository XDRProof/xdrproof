# Address credentials V2: the signature payload is bound to the address (/docs/corpus/entries/auth-address-v2-credentials)

Where it sits, inside `LedgerCloseMeta` (CAP-0071):

- H-B15: SorobanCredentials.SOROBAN_CREDENTIALS_ADDRESS_V2

## The shape

SOROBAN_CREDENTIALS_ADDRESS_V2 (CAP-0071-02): same fields as ADDRESS, but the signed payload includes the address. Readers that only know source-account and ADDRESS credentials fail to parse it or verify it.
