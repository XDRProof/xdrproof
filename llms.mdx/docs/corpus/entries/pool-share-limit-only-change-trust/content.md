# CHANGE_TRUST that only changes a pool-share trustline's limit (/docs/corpus/entries/pool-share-limit-only-change-trust)

Where it sits, inside `LedgerCloseMeta` (CAP-0038):

- H-C8: ChangeTrust on a pool-share asset that only updates the limit

## The shape

A pool-share trustline's limit changes and nothing else: no pool row is touched. wallet-backend#755 assumed a pool-share change always meant a pool update.
