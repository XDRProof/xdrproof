# A config upgrade that unfreezes keys (/docs/corpus/entries/upgrade-config-restore-and-unfreeze)

Where it sits, inside `LedgerCloseMeta` (CAP-0046, CAP-0077):

## The shape

A config upgrade restores the Soroban transaction limit and unfreezes the three trustlines: the frozen-key list returns to empty, visible only in upgradesProcessing.
