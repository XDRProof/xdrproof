# EXTEND_FOOTPRINT_TTL from a muxed source with a text memo (/docs/corpus/entries/muxed-soroban-ttl-tx-source-text-memo)

Where it sits, inside `LedgerCloseMeta` (CAP-0027, CAP-0046):

- H-A9: muxed Transaction.sourceAccount and MEMO_TEXT on ExtendFootprintTTL
- H-G2: P28 variant, the newest protocol a pre-fix wallet-backend (#753 at f8e5786d) ingests

## The shape

Core refuses a memo or muxed source only on InvokeHostFunction (TransactionFrame::validateSorobanMemo); on TTL and restore operations both are valid. The JS SDK builder refuses them, so this was built by hand. wallet-backend#753 halted on this shape.
