# A data entry whose value is 64 bytes that are not UTF-8 (/docs/corpus/entries/manage-data-binary-64)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-B5: DataValue bytes that are not UTF-8
- H-B6: DataValue at its 64-byte maximum

## The shape

MANAGE_DATA with a 64-byte value (the maximum) alternating 0x00 and 0xff: not text. Readers that decode it as a string corrupt it.
