# A claimable balance created by operation 1 with a muxed operation source, inside a fee bump (/docs/corpus/entries/claimable-balance-id-op-index-1-muxed-source-in-fee-bump)

Where it sits, inside `LedgerCloseMeta` (CAP-0023, CAP-0015, CAP-0027):

- H-A10: ClaimableBalanceID from inner source + seq + op index 1, muxed op source, fee bump

## The shape

The balance ID is the hash of (inner source base account, inner sequence number, operation index 1); the muxed operation source and the fee bump must not change it. Readers that derive it from the fee source, the M address or index 0 get another ID.
