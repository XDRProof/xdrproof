# One ledger upgrades the base fee, both transaction-set sizes and the ledger flags (/docs/corpus/entries/upgrade-generated-header-fee-sizes-flags)

Where it sits, inside `LedgerCloseMeta` (pre-cap, CAP-0038, CAP-0046):

- H-F1: LEDGER_UPGRADE_BASE_FEE, MAX_TX_SET_SIZE, MAX_SOROBAN_TX_SET_SIZE and FLAGS in one ledger; LedgerHeaderExt v1

## The shape

LEDGER_UPGRADE_BASE_FEE, LEDGER_UPGRADE_MAX_TX_SET_SIZE, LEDGER_UPGRADE_MAX_SOROBAN_TX_SET_SIZE and LEDGER_UPGRADE_FLAGS apply in one ledger. The flags upgrade (DISABLE_LIQUIDITY_POOL_TRADING_FLAG) switches the header to LedgerHeaderExt v1. Readers that only handle version and reserve upgrades, or a header without an extension, fail on it.
