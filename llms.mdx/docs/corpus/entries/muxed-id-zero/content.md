# A payment to a muxed address with ID 0 (/docs/corpus/entries/muxed-id-zero)

Where it sits, inside `LedgerCloseMeta` (CAP-0027, CAP-0067):

- H-A2: PaymentOp.destination muxed ID 0

## The shape

A muxed destination whose ID is 0: still an M address, distinct from the plain G account. Readers that treat ID 0 as "no ID" collapse it into the base account.
