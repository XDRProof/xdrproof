# The pre-authorized transaction runs and core removes its signer, with no operation (/docs/corpus/entries/signer-preauth-removed-by-core)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-A4: pre-auth signer removed by core in tx_changes_before
- H-D3: signer removed with no operation

## The shape

When a transaction authorized by a T… signer applies, core removes that signer from the account in tx_changes_before. No SET_OPTIONS names it. Readers that track signers only from operations keep a signer that is gone.
