# A contract call restores an archived entry and overwrites it in one operation (/docs/corpus/entries/archival-automatic-restore)

Where it sits, inside `LedgerCloseMeta` (CAP-0066):

- H-D7: archivedSorobanEntries: restored then updated, same key, one operation

## The shape

SorobanTransactionDataExt v1 marks readWrite[0] archived: the call restores it (restored changes for the entry and its TTL) and then updates it. Readers that expect one change per key, or no restored type in an invoke, get it wrong.
