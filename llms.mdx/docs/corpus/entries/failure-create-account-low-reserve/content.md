# CREATE_ACCOUNT fails with CREATE_ACCOUNT_LOW_RESERVE (/docs/corpus/entries/failure-create-account-low-reserve)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C1: OperationResult.create_account.low_reserve in a closed ledger

## The shape

A transaction whose CREATE_ACCOUNT operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and none of its operations change state. The result carries the operation's result code (low_reserve). Readers that skip failed transactions lose the fee and sequence change; readers that assume a failed transaction changed something record effects that never happened.
