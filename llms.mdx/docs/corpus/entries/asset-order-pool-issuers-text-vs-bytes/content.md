# A pool whose two issuers sort one way as strkeys and the other as bytes (/docs/corpus/entries/asset-order-pool-issuers-text-vs-bytes)

Where it sits, inside `LedgerCloseMeta` (CAP-0038):

- H-B1: LiquidityPoolParameters asset order by XDR bytes, not strkey text

## The shape

Two ARST assets whose issuers order oppositely as strkey text and as raw key bytes. The pool ID and the asset order in the pool use XDR byte order. js-stellar-sdk#1766 compared strkey text and computed the wrong pool ID.
