# An oversubscribed ledger: the transaction set's base fee is 2000, not the header's 100 (/docs/corpus/entries/surge-classic-oversubscribed)

Where it sits, inside `LedgerCloseMeta` (CAP-0005):

- H-C18: GeneralizedTransactionSet component baseFee 2000 against header base_fee 100

## The shape

101 operations queued for a 100-operation set, bids 3000, 2000 and 1000 per operation: core keeps the two highest and sets the component base fee to the lowest kept bid. The 3000 bidder pays 2000 per operation, less than it bid, more than the header base_fee of 100.
