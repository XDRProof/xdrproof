# MEMO_RETURN mapped to to_muxed_id bytes, the same as MEMO_HASH (/docs/corpus/entries/memo-return-as-bytes)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-A6: MEMO_RETURN carried into the transfer event as to_muxed_id (bytes), indistinguishable from MEMO_HASH

## The shape

CAP-0067 renders MEMO_RETURN in the transfer event as bytes, exactly as MEMO_HASH: from the event alone the two cannot be told apart.
