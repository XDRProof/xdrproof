# A classic payment emits a transfer event (CAP-0067) (/docs/corpus/entries/event-classic-payment-transfer)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-E1: PaymentOp emits a CAP-0067 transfer event

## The shape

Since CAP-0067, classic operations emit the same events as the Stellar Asset Contract: a native payment emits transfer with from, to and the asset. Readers that take payments only from operations, or only from Soroban events, double-count or miss them.
