# A SAC balance held by a contract above int64 (/docs/corpus/entries/sac-contract-balance-above-int64)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-B4: SAC contract balance i128 above int64
- H-B3: token amount above int64 max

## The shape

The issuer mints 2^64 + 2^63 XPF to a contract. Contract balances in a SAC are i128 with no int64 cap, unlike trustlines. Readers that store token balances as int64 overflow.
