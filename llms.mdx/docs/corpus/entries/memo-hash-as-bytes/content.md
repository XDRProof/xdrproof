# MEMO_HASH mapped to to_muxed_id bytes (/docs/corpus/entries/memo-hash-as-bytes)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-A6: MEMO_HASH carried into the transfer event as to_muxed_id (bytes)

## The shape

CAP-0067 renders MEMO_HASH in the transfer event as bytes, indistinguishable from MEMO_RETURN.
