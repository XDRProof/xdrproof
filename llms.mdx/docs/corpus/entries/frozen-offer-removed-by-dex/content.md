# The DEX removes an offer whose seller's trustline is frozen, and moves nothing (/docs/corpus/entries/frozen-offer-removed-by-dex)

Where it sits, inside `LedgerCloseMeta` (CAP-0077):

- H-D12: offer removed by DEX matching because the seller trustline is frozen

## The shape

A path payment reaches the frozen holder's offer first: CAP-0077 removes it without moving assets and matching continues to the maker's offer. The frozen trustline is still updated (liabilities released). Readers that treat every removed offer as filled record a trade that did not happen.
