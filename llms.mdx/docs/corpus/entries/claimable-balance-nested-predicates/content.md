# A claimable balance with nested and/or/not predicates and a B… address event (/docs/corpus/entries/claimable-balance-nested-predicates)

Where it sits, inside `LedgerCloseMeta` (CAP-0023, CAP-0067):

- H-C9: claimable balance with nested and/or/not predicates
- H-A10: ClaimableBalanceID returned in the result as a B… strkey
- H-A5: claimable-balance address B… in a CAP-0067 event topic

## The shape

CREATE_CLAIMABLE_BALANCE with predicate and(not(before_relative 60), or(before_absolute 2100-01-01, unconditional)). The result returns the balance ID as a B… strkey, and the event names it as the destination.
