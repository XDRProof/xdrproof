# A transaction left with an open sponsorship fails txBAD_SPONSORSHIP (/docs/corpus/entries/failure-tx-bad-sponsorship)

Where it sits, inside `LedgerCloseMeta` (CAP-0033):

- H-C3: TransactionResult.txBAD_SPONSORSHIP
- H-C1: txBAD_SPONSORSHIP: a failed transaction whose operations report success

## The shape

BEGIN_SPONSORING_FUTURE_RESERVES without the matching END in the same transaction: every operation succeeds, then the transaction fails with txBAD_SPONSORSHIP and nothing it did is kept. Its fee is charged and its sequence number consumed. Readers that take operation results at face value record sponsorship that never happened.
