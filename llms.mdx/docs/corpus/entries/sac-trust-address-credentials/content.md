# SAC trust() for a trustor who is not the transaction source creates a trustline (/docs/corpus/entries/sac-trust-address-credentials)

Where it sits, inside `LedgerCloseMeta` (CAP-0073, CAP-0046):

- H-D1: InvokeHostFunction trust() with address credentials creates the trustor's trustline

## The shape

alice submits, carol is the trustor: carol authorizes with address credentials and a nonce. The trustline is carol's; nothing names it but the created entry. wallet-backend#731 dropped such trustlines.
