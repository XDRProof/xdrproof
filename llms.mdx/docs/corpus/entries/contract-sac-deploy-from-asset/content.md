# A Stellar Asset Contract deployed from a classic asset (/docs/corpus/entries/contract-sac-deploy-from-asset)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-D5: HostFunction.CREATE_CONTRACT from ContractIdPreimage.FROM_ASSET; executable STELLAR_ASSET

## The shape

CREATE_CONTRACT (v1 host function) with a contract-ID preimage from the asset XPF: the instance's executable is stellar_asset, not a Wasm hash. Readers that expect every contract to have Wasm code fail on SACs.
