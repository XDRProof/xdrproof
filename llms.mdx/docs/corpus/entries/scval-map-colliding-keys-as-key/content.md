# A map whose five keys collide on native conversion, used as a storage key (/docs/corpus/entries/scval-map-colliding-keys-as-key)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-B2: colliding ScMap as a ContractData key and event topic
- H-D10: contract-data identity depends on the exact ScVal key

## The shape

The colliding map (u32 1, i32 1, u64 1, string "1", symbol 1) is the contract-data KEY: it sits in the LedgerKey and the event topic. Converting it to a native object collapses the keys and changes the entry identity. js-stellar-sdk#1789.
