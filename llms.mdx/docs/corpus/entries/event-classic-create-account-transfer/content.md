# CREATE_ACCOUNT: the new account appears as a CREATED entry and as a CAP-0067 transfer event (/docs/corpus/entries/event-classic-create-account-transfer)

Where it sits, inside `LedgerCloseMeta` (pre-cap, CAP-0067):

- H-E1: CreateAccountOp emits a CAP-0067 transfer event of native XLM to the new account

## The shape

Two CREATE_ACCOUNT operations in one transaction, each funding a new account with 1000 XLM. Each operation's meta holds the funder's state and update and the new account as a created entry, and, since CAP-0067, a transfer event of native XLM from the funder to the new account. Readers that count transfer events as payments double-count account funding; readers that only watch payment operations miss it.
