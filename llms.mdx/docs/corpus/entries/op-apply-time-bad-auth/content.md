# An operation whose source signer was removed earlier in the ledger fails opBAD_AUTH (/docs/corpus/entries/op-apply-time-bad-auth)

Where it sits, inside `LedgerCloseMeta` (CAP-0046):

- H-C16: OperationResult.opBAD_AUTH in a closed ledger: operation-source signer removed earlier in the ledger

## The shape

Core applies a ledger's classic phase before its Soroban phase and re-checks the source account, sequence number, signatures and sequence-age preconditions at apply (TransactionFrame::commonValid; OperationFrame::checkSignature with forApply). Here a classic transaction earlier in the same ledger removes the key that signed for this transaction's operation source, so the transaction fails with txFAILED and the operation result opBAD_AUTH, while the transaction-level signature is still valid.
