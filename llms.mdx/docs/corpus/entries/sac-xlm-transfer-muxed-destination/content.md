# An XLM SAC transfer to a muxed address: the event splits it into to and to_muxed_id (/docs/corpus/entries/sac-xlm-transfer-muxed-destination)

Where it sits, inside `LedgerCloseMeta` (CAP-0067):

- H-E2: transfer event data map with to_muxed_id u64
- H-A11: event splits M into to and to_muxed_id

## The shape

The transfer argument is M(bob, 2^64-1). The event names bob's G address in topics and carries the ID as to_muxed_id (u64) in a data map instead of a bare i128.
