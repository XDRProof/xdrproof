# PAYMENT fails with PAYMENT_SRC_NO_TRUST (/docs/corpus/entries/failure-payment-src-no-trust)

Where it sits, inside `LedgerCloseMeta` (pre-cap):

- H-C1: OperationResult.payment.src_no_trust in a closed ledger

## The shape

A transaction whose PAYMENT operation fails at apply is still written into the closed ledger: its fee is charged, its sequence number is consumed, and none of its operations change state. The result carries the operation's result code (src_no_trust). Readers that skip failed transactions lose the fee and sequence change; readers that assume a failed transaction changed something record effects that never happened.
