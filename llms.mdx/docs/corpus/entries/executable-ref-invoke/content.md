# Calling a contract whose code comes from a reference (/docs/corpus/entries/executable-ref-invoke)

Where it sits, inside `LedgerCloseMeta` (CAP-0085):

- H-D11: InvokeHostFunction on an external-ref contract

## The shape

The external-ref contract runs the v1 kit's put: its footprint must include the owner's tag entry and the referenced Wasm.
